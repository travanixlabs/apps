    Settings

    ● Saved

    Where the app opens on launch, and where the home button in the breadcrumb goes.

    Names, comma separated, applied at the default folder only. The sync root keeps Documents, Music and the rest beside your libraries; this hides them without hiding anything deeper in. Leave it blank to list everything.

    Live needs no pre-processing: hovering seeks the real file and plays it. Cached stills take about a second per video the first time, then cost nothing to re-hover.

    Changing frame count or tile width rebuilds previews on next hover. Existing sprites stay cached under .cache.

    The size, the dwell and the details take effect at once, so the grid behind this can be judged while you set them.

    Colours

    Renaming a label renames it on every video that carries it, and deleting one takes it off every video. Neither can be undone from here, so a delete asks first and says how many videos it will touch.

    Every change saves immediately. Esc closes.
